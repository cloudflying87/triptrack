CSV Format Instructions

Your CSV file should have the following columns:

  • date (required) - Format: MM/DD/YY or MM/DD/YYYY or YYYY-MM-DD
  • event_type (optional) - Type of event: outing, gas, or maintenance (defaults to outing)
  • hours (optional) - Engine hours reading
  • miles (optional) - Odometer reading
  • gallons (optional) - Fuel amount
  • location (optional) - Location name
  • notes (optional) - Any notes about the event

Example:

date,event_type,hours,gallons,location,notes
4/13/24,outing,912.0,,Marion,Rena and Theo - combined temp 102
5/1/24,gas,912.9,10,Marion,Rena - wind 260@11G20
